# Investor One-Pager — Document Structure Template

Canonical structure for every one-pager the app generates. Contains **no company data** — only the
blocks, labels, field bindings, formats and limits that each generated document must follow.

`{{ token }}` = a value bound from the extracted `OnePager` model. Every token resolves through the
null and confidence rules below before it reaches the page.

---

## 0. Document-wide rules

| Rule | Value |
|---|---|
| Page size | US Letter portrait, 612 × 792 pt (8.5in × 11in) |
| Margins | 0.5 in on all sides |
| Page count | **Exactly 1** — never spill to a second page |
| Null value | render `—` (em dash) in the muted colour; never a guess, never a blank gap |
| Low confidence | `confidence < {{ min_confidence }}` (default 0.60) renders a superscript `†` after the value |
| Section labels | ALL CAPS, small, letter-spaced, accent-coloured; identical wording every time |
| Currency | short form: `$750K`, `$2M`, `$1.8B`. Non-USD keeps the deck's currency and is footnoted |
| Empty list field | render the label and a single `—`; never omit the block |
| Typography | serif headings / sans body; 22 / 11 / 9.5 / 8 pt |
| Palette | near-black text, one accent, one neutral gray — all as CSS custom properties |

## 1. Layout map

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [logo]  {{ company_name }}                          {{ stage }}          │  header ~0.9in
│         {{ tagline }} · {{ website }}               {{ sector }} · {{ hq_location }} │
├──────────────────────────────────────────────────────────────────────────┤
│ RAISE     PRE-MONEY    INSTRUMENT     COMMITTED      CLOSE               │  ask strip ~0.5in
│ {{ … }}   {{ … }}      {{ … }}        {{ … }}        {{ … }}             │  (tinted background)
├────────────────────────────────────┬─────────────────────────────────────┤
│ PROBLEM                            │ TRACTION                            │
│ SOLUTION                           │ MARKET                              │  body ~7.2in
│ BUSINESS MODEL                     │ TEAM                                │  left 58% / right 42%
│ GO-TO-MARKET                       │ COMPETITION                         │
│ USE OF FUNDS                       │                                     │
├────────────────────────────────────┴─────────────────────────────────────┤

```

## 2. Header block

| Slot | Token | Format | Limit |
|---|---|---|---|
| Logo | `{{ firm_logo }}` | left-aligned image, ~0.67in × 0.25in | — |
| Company name | `{{ company_name }}` | 22 pt bold serif | 1 line, truncate with ellipsis |
| Tagline | `{{ tagline }}` | 10 pt, follows the name | ≤ 90 chars |
| Website | `{{ website }}` | appended to the tagline after a `·` separator | 1 line |
| Chips (right) | `{{ stage }}` · `{{ sector }}` · `{{ hq_location }}` | pill chips, stage first | 1 line each |
| Not shown on page | `{{ sub_sector }}`, `{{ founded_year }}` | carried in the JSON only | — |

`{{ stage }}` is one of: Pre-Seed · Seed · Series A · Series B · Series C+ · Growth · Unknown.

---

## 3. The Ask strip

Five evenly spaced label-value cells, fixed order, fixed labels:

| Cell label | Token | Format |
|---|---|---|
| `RAISE` | `{{ raise_amount_usd }}` | short currency |
| `PRE-MONEY` | `{{ pre_money_valuation_usd }}` | short currency |
| `INSTRUMENT` | `{{ instrument }}` | free text, wraps to 2 lines then truncates |
| `COMMITTED` | `{{ amount_committed_usd }}` | short currency |
| `CLOSE` | `{{ close_date }}` | as stated in the deck |

`{{ min_check_usd }}` is captured in the JSON but has no cell — surface it in the analyst block only
if a partner would need it.

---

## 4. Left column (58%)

Fixed order. Each block = ALL CAPS label + one paragraph, no sub-headings.

| Label | Token | Limit |
|---|---|---|
| `PROBLEM` | `{{ problem }}` | ≤ 320 chars |
| `SOLUTION` | `{{ solution }}` | ≤ 320 chars |
| `BUSINESS MODEL` | `{{ business_model }}` | ≤ 220 chars |
| `GO-TO-MARKET` | `{{ go_to_market }}` | ≤ 220 chars |
| `USE OF FUNDS` | `{{ use_of_funds[] }}` | ≤ 4 bullets, ≤ 70 chars each |

`USE OF FUNDS` renders as a bulleted list; every other block is prose in the founders' own framing,
compressed but not editorialised.

---

## 5. Right column (42%)

### TRACTION

Metric tiles in a 2-up grid, maximum 6, in priority order:
**revenue → growth rate → customers → retention → pipeline → partnerships.**

```
{{ metric.value }}
{{ metric.label }} · {{ metric.period }}
```

`value` keeps the deck's own notation (`$1.2M`, `18%`, `3 LOIs`). `period` is omitted with its
separator when null. `metric.source_slide` is carried in the JSON, not printed.

### MARKET

Three stacked figures, then one note line:

```
TAM {{ tam_usd }}    SAM {{ sam_usd }}    SOM {{ som_usd }}
{{ market_note }}
```

`{{ market_note }}` carries the sizing methodology and any adjacent-market claim.

### TEAM

Maximum 4 people, founders first:

```
{{ member.name }}  {{ member.role }} — {{ member.background }}
```

`role` may carry a commitment qualifier in parentheses (e.g. full-time / part-time / advisory) when
the deck states one. `background` ≤ 90 chars.

### COMPETITION

```
{{ competitors[] joined by " · " }}          ≤ 5 named competitors
{{ differentiation }}                        ≤ 200 chars
```

---

## 6. Analyst block

Visually distinct — lighter background — and always introduced by the italic label
`{{ firm_name }} analysis — AI-generated`, so it can never be mistaken for founder claims.

Three columns, fixed order and fixed counts:

| Column label | Token | Count | Rule |
|---|---|---|---|
| `STRENGTHS` | `{{ key_strengths[] }}` | exactly 3 | ≤ 90 chars each; cite the evidence, not a category |
| `RISKS` | `{{ key_risks[] }}` | exactly 3 | ≤ 90 chars each; must be specific to this company — never "execution risk" or "competitive market" |
| `REQUEST FROM FOUNDER` | `{{ missing_information[] }}` | up to 5 | diligence items needed before an IC discussion |

---

## 7. Footer

```
Generated by {{ firm_name }} · {{ source_filename }} · {{ extracted_at:%d %b %Y } · Internal use only
{{ low_confidence_count }} field(s) † below {{ min_confidence_pct }} confidence — verify before relying on it
```

The second line is omitted when `low_confidence_count == 0`.

---

## 8. Overflow policy

The page is measured after render. While it exceeds one page, truncate in this order, appending an
ellipsis and logging each truncation:

1. `{{ go_to_market }}`
2. `{{ business_model }}`
3. `{{ differentiation }}` / `{{ competitors[] }}`
4. `{{ market_note }}`

Header, ask strip, traction, team and the analyst block are never dropped — a one-pager without them
is not a one-pager.

---

## 9. Provenance (JSON only — never printed on the page)

`source_filename` · `source_page_count` · `extracted_at` · `model` · `input_tokens` ·
`output_tokens` · `estimated_cost_usd`

Every printed field additionally carries `confidence`, `source_slides` and an optional `note` in the
JSON, so any claim on the page can be traced back to the slide it came from.
